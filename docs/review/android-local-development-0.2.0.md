# Android transition diagnostics and owned lifecycle fixture

Date: **2026-10-05**. Scope: **local inspector 0.2.0 and owned fixture 0.1.0 build/JVM preparation**. The user's [qualitative first-phone feedback](android-phone-feedback-2026-10-05.md) motivated this step and remains separate from automated evidence. It does not establish AliExpress's internal implementation or measured accuracy. No further phone/account input was needed to build this step.

The [updated inspector](../../artifacts/android-local-inspector/liveabit-local-inspector-0.2.0.apk) labels Activity resume/pause records, explains internal screen handoffs, exposes inferred closed interval counts/times and displays plain uncertainty reasons. Its total remains the sum of closed candidate intervals; genuine pause-to-resume gaps are excluded, overlap is counted once, and conflicting/missing/open observations are not repaired by guessing. At most eight recent closed intervals per selected app and 64 recent transitions are rendered, with explicit truncation wording. The collector's reconstruction/permission/storage behavior is unchanged.

The separate [owned lifecycle fixture](../../artifacts/android-local-inspector/liveabit-lifecycle-fixture-0.1.0.apk) has two authored screens, opaque own-callback tokens and bounded RAM-only type/time records. It requests zero permissions, observes no other app and persists no data. Begin/Finish define an interior measurement window using the fixture's own known resumed state. It preserves genuine gaps and counts overlapping own callbacks as a union. Invalid order, clock discontinuity, record/run limits and reset prevent usable results. This baseline is never a production collector coverage attestation.

The inspector's collapsed optional test panel appears only when `org.liveabit.fixture` is selected in an active session. The user manually enters the fixture window/value. A pure fixed-package comparator clips already retained closed estimates to that window; it performs no query or IPC, cannot access pre-consent/unqueried ranges, preserves unknown results and returns no pass threshold. Manual values are unverified. Inputs/results clear on leaving, changing scope or resetting/stopping the session. A review fix also ensures a newly stopped checked report refreshes the main screen before comparison's early parsing return.

## Verification

The [current native manifest](android-local-inspector-validation.json) governs exact tool/source hashes, APK identities/digests/signatures/permissions, lint counts and executed outcomes. The prior [0.1.0 manifest](android-local-inspector-0.1.0-validation.json) is preserved. Current verification rebuilds both APKs and executes both independent JVM harnesses before actual binary audits; the fixture counter parses its declared executed-case total rather than counting its one summary line.

- 30 collector/comparison cases cover the original 19 boundaries, fragmented transitions across queries, short gaps, ambiguous same-millisecond handoffs, overlap union, fixed-package window clipping, absent/open evidence, authority/horizon/input bounds, comparison purity and immutable warnings.
- 25 independent owned-fixture cases cover interior markers, gaps, overlap, provisional/finished values, malformed callback order, caller identity, invalid/paired clocks and cumulative drift, exact record/time limits, Clear/fresh Begin/reset, frozen navigation and token-free immutable outputs.
- Android compilation, lint, actual APK permission/API/package/version audits and debug-signature checks are distinct from those JVM results. Neither new APK was installed or run on Android by these checks.

Independent source review found no remaining material blocker after the control-display, Insets and test-count corrections. The [phone guide](../../android/README.md) describes the optional later idle/internal-screen comparison. Both APKs lack Internet permission and delivery components. Agent selection, Linux portability, background scheduling, battery trials, measured accuracy/support thresholds, production signing/distribution and M2/M3 remain deferred or unproven.
