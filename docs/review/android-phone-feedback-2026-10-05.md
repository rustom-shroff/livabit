# First Android phone feedback

Date: **2026-10-05**. Evidence type: **qualitative user report**, not an instrumented or independently observed measurement. The user previously identified their owned Android 15+ phone as the trial environment. Exact OS/API revision, OEM/model and installed APK hash were not supplied or independently verified. The most recent delivered build was local inspector 0.1.0; its [versioned build audit](android-local-inspector-0.1.0-validation.json) remains separate.

The user reported that the app appeared to work during testing to the best of their ability. YouTube produced clean pause/resume events. AliExpress produced multiple pause/resume events during interaction without an apparent exit from the app; leaving it idle produced one pair. The inferred time appeared reasonable. No raw event trace, numeric timing baseline, content, credentials or other private activity was requested or retained.

Android documents `ACTIVITY_RESUMED` and `ACTIVITY_PAUSED` per Activity, including each Activity within a package. Internal screen handoffs can therefore create several transitions during one apparent app visit. That is consistent with the report but does not identify AliExpress's actual cause. Package-only events cannot resolve Activity identities, current attention, visibility or complete source continuity. [Usage event reference](https://developer.android.com/reference/android/app/usage/UsageEvents.Event), [lifecycle coordination](https://developer.android.com/guide/components/activities/activity-lifecycle)

The report supports continuing local collector development. It does not establish numeric accuracy, permission/revocation races, restart/lock/clock behavior, background reliability, battery cost, an OEM support matrix or M3. No real agent or direct delivery has been tested. Agent selection and Linux portability remain deferred.
