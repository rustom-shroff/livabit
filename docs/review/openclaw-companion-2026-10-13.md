# OpenClaw companion reminder review

Date: **2026-10-13**. [ADR-0023](../decisions/0023-openclaw-companion-reminders.md), [setup guide](../integration-drafts/openclaw-companion-notifications.md), [machine-readable evidence](openclaw-companion-2026-10-13.json).

The user's official Android companion, `ai.openclaw.app`, was already paired and connected to OpenClaw. The installed gateway is **2026.9.9** and the phone reports **2026.9.80**. Its declared `system.notify` command and notification permission were verified before selecting it as the private destination. One explicitly labelled **liveabit connection check** was invoked through the native command. The exact selected node acknowledged `ok: true` and `command: system.notify`; **the user confirmed that the notification appeared from OpenClaw on their phone**. This is new-route evidence, independent of the earlier WhatsApp confirmations.

The dedicated liveabit agent now uses the native nodes tool for companion reminders. Its instructions retain shared Workboard task checks, priority/deadline/next-step context, meaningful-activity rules, quiet hours, cooldown and processed-event handling. Ordinary hook replies remain local (`deliver: false`). The old owned main/liveabit WhatsApp reminder policies are disabled, the legacy helper cannot restore WhatsApp over a companion policy, and generic setup no longer copies main's old route. Both agents' model and reasoning choices and both saved reminder-state files were compared before/after and preserved byte for byte. Existing preferences remain **60 minutes** and **22:00–08:00 America/Chicago**.

The permanent native PowerShell suite passed **19 cases / 68 assertions** on **Windows PowerShell 5.1.26100.9549** and **PowerShell 7.6.5**. It executes the actual embedded helper code with an isolated synthetic CLI, not a JavaScript sender prototype. Cases cover migration/state/configuration preservation, opt-out and quiet-hour settings, real default Chicago compatibility, permission and ambiguity rejection, both legacy guards, five invalid acknowledgement variants without retries, saved-phone reuse and explicit device changes. These fixtures sent no real notifications; the separate native phone check sent exactly one.

The first live migration stopped before writing policies because the managed Windows runtime did not recognize the IANA Chicago name. The helper now validates its Windows equivalent while retaining the original IANA preference; the real default is covered on both PowerShell versions. Migration then succeeded. Task setup applied the new instructions/tool selection and its bounded readiness check waited for the existing managed gateway to become healthy. No additional gateway or repair restart was launched. A successful helper rerun preserved the companion destination, preferences and reminder-state bytes.

The **0.11.0-poc Android sender APK is unchanged**, retaining SHA-256 `d82254c29584cb45d9472c08da21110085545c25de33c95022b06d27184e09de` and its [95-check emulator evidence](android-setup-regressions-2026-10-13.md). The existing Wi-Fi export passed its authenticated empty-object hook check after migration, with the expected missing-message HTTP 400 and no model run. No APK rebuild, OAP schema change, hosted relay, task mutation, model switch or global WhatsApp account change was introduced. Private device identity, policies, task data, keys and diagnostic files remain outside Git. Independent source review found no production blockers.

Notification display is confirmed for the connection check. Automatic task-grounded reminder quality is not established by that check. The companion must stay connected to a reachable gateway; Android offline notification recovery is not promised. Cooldown, quiet hours and duplicate handling remain agent instructions, and the broad nodes tool has no separate per-action enforcement configuration in this installed release.

## Next steps

Keep the OpenClaw companion connected and manage real tasks in main's conversation. Continue using the existing liveabit APK. Development can continue independently; no approval or required phone test is pending.
