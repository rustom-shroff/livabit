# First real-activity phone trial

**Latest confirmation, 2026-10-12:** The user reported **“OpenClaw acknowledged activity”** from their physical Android phone over Wi-Fi after the exported address was corrected and the approved scoped Windows Firewall exception was applied. [Phone admission confirmation](../review/openclaw-phone-delivery-2026-10-12.md). The connection trial is complete and independent development can continue without another connection retry. Goal-grounded coaching remains a separate optional trial below; goals stay in OpenClaw. The phone's APK version/hash was not independently read, and the separate 0.8.0 emulator evidence remains unchanged.

The WhatsApp checks [arrived with a phone notification](../review/openclaw-phone-notification-2026-10-11.md), and phone activity admission is now user-confirmed. The exact-byte emulator-tested [liveabit Sender 0.8.0 APK](../../artifacts/android-publisher/liveabit-sender-0.8.0-poc.apk) is available for the following optional goal-grounded trial using the working connection.

1. In the main OpenClaw conversation that receives liveabit observations, describe one goal you actually want help with, when it applies, and the kind of reminder you want. Your goals and model choices stay in OpenClaw. A goal given in another chat is not assumed to be available here.
2. Copy the APK and private `artifacts/openclaw/android-wifi-setup.json` to your phone. Keep the computer running and both devices on the same reachable Wi-Fi network. If your network/address has changed, run `.\scripts\configure-openclaw.ps1 -AgentId main -Lan` from the project root to regenerate that setup. This preserves your model choices and existing private delivery policy. [Connection guide](../../android/publisher-app/README.md).
3. Install the APK, import that setup, in **Setup** check that the connection identifies **OpenClaw (main)**, choose the apps you want to share and enable usage access. **Settings** contains sending intervals and receiver warnings. In **Activity**, tap **Start sharing**. Importing a file alone does not turn sharing on.
4. Use one selected app normally, return to liveabit and tap **Send now**. Look for **OpenClaw accepted activity for processing**, a recent acknowledgement and no pending events. Then check that the observation appears in the receiving main conversation.
5. Let the agent apply your goal and preferences. Ordinary observations stay in OpenClaw; a WhatsApp nudge is selective rather than a receipt for every send. Defaults are a 60-minute cooldown and quiet hours 22:00–08:00 America/Chicago. No established goal means no behavioral nudge. [Notification settings](openclaw-whatsapp-pairing.md).

Automatic sends now target five minutes when there is new selected-app activity and pause after fifteen minutes with the screen off. Both values are editable in Settings; Android can delay jobs. **Send now** avoids waiting for that schedule during the initial trial. **Stop sharing** ends scheduled sends and clears pending activity. The receiver-down warning defaults to 60 minutes without acknowledgement and can be changed in the app.
