This optional phone trial evaluates useful coaching; development can continue without another connection retest.

1. In your existing main OpenClaw conversation, add an actual task you want help with. Include its priority, an explicit deadline if it has one, and a concrete next step. Main's personal-tasks Skill stores it in Workboard for liveabit to read. Example wording: “Add my job application task with high priority, deadline Friday and next step review the resume.” Use your real task details in OpenClaw; nothing needs to be pasted here. This uses ordinary tasks, not OpenClaw's internal Goal primitive.
2. Transfer the APK to your phone. If 0.9.0 already has a working liveabit connection, keep that setup. For a new connection, generate it with `.\scripts\configure-openclaw.ps1 -AgentId liveabit -Lan` and transfer private `artifacts/openclaw/android-wifi-setup.json`. Keep the computer running and both devices on reachable Wi-Fi. Setup preserves models and the existing verified self-chat policy. [Connection guide](../../android/publisher-app/README.md).
3. Install 0.10.0 over the existing app. Sharing that was on remains on without another Start; a previously stopped sender remains stopped. For a new or older mapped main connection, use **Import receiver file** in Setup and check **OpenClaw (liveabit)**. Tap **Connect to OpenClaw** for an immediate key/path/reachability check; an error remains visible there. Select Apps to share and enable usage access/warnings, then Start sharing once if it is stopped. Import/check alone does not start sharing.
4. Use a selected app normally, return to liveabit and tap **Send now**. Only positive selected-app duration produces an OpenClaw packet; “nothing sent” is expected when no meaningful monitored activity is available. When activity is sent, look for admission acknowledgement and inspect the receiving liveabit conversation. Admission is distinct from interpretation.
5. Let liveabit consider open tasks, priority, deadline and next step. A useful WhatsApp nudge is selective, rather than a receipt for every observation. No task or insufficient context means silence. Default policy is a 60-minute cooldown and quiet hours 22:00–08:00 America/Chicago. Synthetic checks and duplicate observations do not justify nudges. [Delivery policy](openclaw-whatsapp-pairing.md).

Automatic activity sends target five minutes and pause after fifteen minutes screen-off; both are configurable in Settings. Closing the app leaves sharing enabled. After phone shutdown/restart and the first unlock, monitoring resumes without opening liveabit; previously stopped sharing stays stopped. Android may delay jobs, and Force stop blocks background work until reopening. Stop sharing cancels scheduled sending and clears pending activity. Receiver warnings default to 60 minutes without acknowledgement and are independent of WhatsApp nudges. Precise duration, complete coverage and battery behavior remain deferred or unproved.
